# Omnigent に送るプロンプト（Step 1 データの準備）

**このプロンプトで頼んでいること**: 自分のスキーマに、ハンズオンで使うデータ（CRM・ディープリサーチの結果・Memory）を用意するノートブックを作ってもらう。

```
## やりたいこと
ハンズオンで使うデータを、自分のスキーマに用意するノートブックを作ってください。

## 作るもの
- ファイル: handson/my_work/01_prepare_data.py（ノートブック）
- 中身:
  1. 自分のスキーマを作る（なければ）
  2. data/crm_accounts.json から、テーブル crm_account を作る
  3. Volume research を作り、data/research/ の会社ごとのフォルダをそのままコピーする
  4. Managed Agent Memory（agent_memory）を作り、scope "shared" に採点の共通ルールを 1 件入れる
     （ルールの趣旨: 重要インフラ・古いシステム・人材不足・規制業種・直近のインシデントの会社ほど見込みが高い。
      クラウドネイティブで修正の対象が小さい会社や、競合が入っていて提案の余地がない会社は低い）
  5. 共有の AI Search のインデックスで「病院 電子カルテ 人手不足」を検索し、自分から検索できることを確かめる

## 決まりごと
- 名前（カタログ・スキーマ・テーブル・Volume・Memory・インデックス）は直接書かず、%run ../_config で読み込んだ変数を使う
- すでにあるもの（スキーマ・Memory・共通ルール）は、作り直さない
- 過去の受注事例のテーブルとインデックスは、代表者が共有スキーマに作ったものを使う（作らない）
- 各セルの最後で、作ったものを表示する。セルの説明は日本語の Markdown セルで書く
```
