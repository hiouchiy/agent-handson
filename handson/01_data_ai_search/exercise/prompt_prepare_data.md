**このプロンプトで頼んでいること**: 用意してあるデータの準備のノートブック（`solution/01_prepare_data`）の中身を説明してもらい、そのまま実行してもらう。
データの準備は誰が書いても同じになるので、ゼロから書かずに、用意したものを使います。

```

   （特に、Managed Agent Memory を作って共通ルールを入れるところ）

   （/Workspace/Users/<user_email>/<materials_folder>/handson/01_data_ai_search/solution/01_prepare_data）を、
   handson/tools/run_notebook.sh で実行してよいか聞いてください
```
