# Genie Code への質問の例（Step 3 NG の理由を調べる）

評価の画面・トレース・`rubric.py` のどれかを開いた状態で、Genie Code（画面右上の Assistant）に質問します。
開いている画面の内容を踏まえて答えてくれます。

## まず全体をつかむ
- この評価で NG になったのは、どの評価データの、どのスコアラーですか？ それぞれの理由を短くまとめてください。
- 直す前の評価と直した後の評価で、結果が変わったスコアラーを表にしてください。

## 1 件ずつ深掘りする
- E001 の関係性の補正は、どの段階・何点で、根拠は何ですか？ 期待する範囲に入らなかった理由を説明してください。
- E002 の ④企業規模・予算 は何段階になっていますか？ rubric.py のどの基準でその段階になったのか教えてください。
- E003 の next_action を表示してください。評価データの guidelines のどこを満たしていませんか？
- このトレースで、AI Search はどの事例を返しましたか？ その事例は採点のどこで使われましたか？
- このトレースで、Managed Agent Memory から読んだ内容は何ですか？

## 直し方を相談する
- E001 を期待どおりにするには、採点基準を変えるべきですか？ それとも足りない情報を足すべきですか？ 理由も教えてください。
- E002 の期待値は、rubric.py の基準と食い違っていますか？ 食い違っているなら、どちらを直すのが自然ですか？
- E003 で、エージェントに next_action の書き方を守らせるには、どのプロンプトに何を足せばよいですか？

## データで確かめる（SQL）
- 自分のスキーマの scoring_otel_spans テーブルから、直近のトレースで時間がかかった処理の上位 5 つを出してください。
- 評価データセット（scoring_eval_dataset）の中身を表示してください。
